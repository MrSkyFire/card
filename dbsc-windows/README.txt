DragonBall Saga Windows Local Server

Run DBSC.exe.

DBSC.exe starts the bundled native server executable and automatically connects its built-in client to 127.0.0.1:4000.

External MUD clients may connect to:
  127.0.0.1:4000     (same PC)
  <your LAN IP>:4000 (other devices on the LAN)

The world/data folders remain external. Editing areas, help, races, classes, system files, player files, etc. does not require recompiling either executable. Restart the server to reload changes where applicable.

The game engine itself is C. Engine/source changes still require rebuilding the server executable.
